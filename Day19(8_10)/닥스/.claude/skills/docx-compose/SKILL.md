# .docx 조립

## 실행

```bash
# 의존성 — 매번 이 줄로 확인한다. 이미 있으면 즉시 통과한다
.venv/bin/python -c 'import docx' 2>/dev/null || {
    python3 -m venv --clear .venv && .venv/bin/pip install -q python-docx pillow
}

.venv/bin/python .claude/skills/docx-compose/scripts/build_docx.py \
    _workspace/03_manuscript.md \
    "MSA_개인과제_보고서.docx" \
    --images-dir _workspace/diagrams
```

`--images-dir`을 주면 마크다운의 `![](x.png)`에서 파일명만 떼어 그 디렉토리에서 찾는다.
원고를 옮겨도 이미지 경로가 깨지지 않는다.

## 원고 마크다운에서 쓸 수 있는 것

스크립트는 마크다운 전체를 지원하지 않는다. 템플릿2 보고서가 실제로 쓰는 요소만 처리한다.

| 문법 | 결과 |
|---|---|
| `#` `##` `###` | 제목 1~3단계 (2단계는 남색) |
| 그냥 문단 | 본문 10.5pt, 줄간 1.5 |
| `- 항목` | 불릿. 앞에 공백 2칸이면 2단계 |
| `| 표 |` + 구분줄 | Table Grid, 헤더 행 회색 배경 |
| ` ```…``` ` | 고정폭 + 회색 배경 |
| `![](그림.png)` | 가운데 정렬 이미지 |
| 이미지 다음 줄의 `> 캡션` | 회색 9pt 캡션 |
| 줄 맨 앞 `>` (이미지 뒤가 아닐 때) | 들여쓴 회색 인용문 — 강의 자료·코드 주석 인용에 쓴다 |
| `---` | **쪽 나눔** |
| `**굵게**` `` `코드` `` | 문단 안 인라인 서식 |

지원하지 않는 것: 중첩 서식(`**`굵은 코드`**`), 번호 목록, 각주, 링크.
번호가 필요하면 `- 1) 내용` 처럼 불릿 안에 직접 쓴다.

## 이미지 크기

가로는 본문 폭 16cm에 맞추되, 세로가 13cm를 넘지 않도록 비율로 줄인다.
세로로 긴 손그림(계층형 다이어그램)이 한 쪽을 통째로 잡아먹는 사고를 막는 장치다.

더 작게 넣고 싶으면 스크립트를 고치지 말고 다이어그램 캔버스 자체의 가로세로비를
바꿔라. 문서에서 축소하면 손글씨 획이 뭉갠 것처럼 보인다.

## 쪽 나눔은 손으로 잡는다

Word는 자동으로 쪽을 나누고, 그러다 보면 제목 하나가 앞 쪽 맨 아래에 혼자 남는다.
원고에서 절이 바뀌는 지점에 `---`를 넣어 직접 끊어라. 조립 후 반드시 쪽 수와
어색한 끊김을 확인한다.

## 확인

```bash
python3 -c "
import zipfile, re
x=zipfile.ZipFile('MSA_개인과제_보고서.docx').read('word/document.xml').decode()
print('문단', len(re.findall(r'<w:p[ >]', x)), '| 이미지', x.count('<pic:pic'), '| 표', x.count('<w:tbl>'))"
```

이미지 개수가 넣은 PNG 수와 다르면 경로가 틀린 것이다. 스크립트는 없는 이미지를
경고만 찍고 넘어가므로(문서 생성 자체는 성공한다) 이 확인을 건너뛰면 그림 빠진
문서를 제출하게 된다.
